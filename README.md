# NLP_TrigramVsTransformer
This project implements a simple trigram language model in Python. The model learns word patterns from a small training corpus and predicts the next word based on the previous two words. It also includes a basic attention simulation to demonstrate how context can influence predictions in transformer-based models.

# Features
- Cleans and tokenizes text
- Builds trigram word frequencies
- Calculates prediction probabilities
- Predicts the most likely next words
- Demonstrates simple transformer-style attention

# Summary
Through this project, I learned how trigram models use the previous two words to predict the next word based on probabilities learned from training data. I also learned that adding more context improves prediction accuracy and that attention mechanisms help models focus on the most relevant parts of a sentence, allowing them to capture long-range relationships that simple trigram models can't.
